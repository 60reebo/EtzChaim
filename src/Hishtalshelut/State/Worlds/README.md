# State - Worlds

This directory contains per-world state modules:

Modules:
- `EinSofState.agda`: State definition for the EinSof world.
- `IgulimYosherFullState.agda`: State definition for the Igulim/Yosher worlds.
- `TzimtzumState.agda`: State definition for the Tzimtzum world.

Usage:
```agda
import Hishtalshelut.State.Worlds.TzimtzumState
```
