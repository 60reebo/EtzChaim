# Hishtalshelut Runtime Library

ספריית הריצה (Runtime) של מערכת ההשתלשלות והרש"ש

---

## מהות הספרייה
ספרייה זו מהווה את "מנוע הריצה" של הסימולציה: היא מחברת בין הליבה הפורמלית (Agda/Haskell) לבין העולם הדינמי — ומאפשרת להפעיל, להמחיש ולנתח תהליכים חיים של שבירה, תיקון, המשכת אור, מעבר בין עולמות ועוד.

## עקרונות פעולה
1. **State — מצב סימולציה:**
   - ייצוג מלא של המצב הנוכחי (רשימת קורדינטות, ערכי אור/כלי, מצב שבירה/תיקון וכו').
2. **Transitions — פונקציות מעבר:**
   - כל תהליך (step) כתוב כפונקציה שמקבלת מצב ומחזירה מצב חדש.
3. **Simulation Loop — לולאת ריצה:**
   - לולאה שמריצה את הפונקציות (או מקבלת קלט), מעדכנת מצב, ומציגה אותו (ויזואלית/טקסטואלית).
4. **Visualization — המחשה:**
   - כל עדכון במצב מתורגם לאובייקט גרפי/טקסטואלי (עיגול, קו, צבע, תנועה).
5. **Interactivity — אינטראקטיביות:**
   - אפשרות לקלוט קלט מהמשתמש, לעבור שלבים, לשנות פרמטרים, להריץ תהליכים שונים.

## זרימת עבודה מומלצת
1. כותבים את הלוגיקה והטיפוסים ב־Agda (או Haskell).
2. מייצאים/מתרגמים את הפונקציות ל־Haskell.
3. בונים ב־Haskell (או שפה אחרת) את ספריית הריצה:
   - טיפוס מצב (state)
   - פונקציות step/transition
   - לולאת סימולציה
   - חיבור לממשק גרפי/טקסטואלי
4. כל תהליך חדש שנכתב בליבה — ניתן מיד לסמלול והרצה בספריית ה־Runtime.

stepSimulation :: SimState -> SimState

runSimulation :: SimState -> IO ()

## מטרות הספרייה
- לאפשר סימולציה חיה של כל תהליך רוחני־קבלי.
- להמחיש את הלוגיקה הרש"שית בצורה דינמית, אינטראקטיבית וגרפית.
- להוות בסיס להרחבות: דיאגרמות, אנימציות, ממשקי משתמש, ניתוחים מתקדמים.
