# Runtime - Worlds

This directory contains per-world simulation scenarios and scripts for runtime execution:

Modules:
- `EinSofScenario.agda`: Scenario definitions for running EinSof simulations.
- `IgulimYosherScenario.agda`: Scenario definitions for Igulim/Yosher simulations.
- `TzimtzumScenario.agda`: Scenario definitions for Tzimtzum simulations.

Usage:
```agda
import Hishtalshelut.Runtime.Worlds.EinSofScenario
```
