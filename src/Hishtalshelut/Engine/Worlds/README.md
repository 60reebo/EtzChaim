# Engine - Worlds

This directory contains per-world engine modules for simulation:

Modules:
- `EinSofEngine.agda`: Engine logic for the EinSof world.
- `IgulimYosherEngine.agda`: Engine logic for the Igulim and Yosher worlds.
- `TzimtzumEngine.agda`: Engine logic for the Tzimtzum world.

Usage:
```agda
import Hishtalshelut.Engine.Worlds.EinSofEngine
```
