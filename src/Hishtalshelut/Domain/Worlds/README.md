# Domain Worlds

This directory contains the core domain definitions for individual worlds in EtzChaim.

Modules:
- `EinSof.agda`: Domain definition for the EinSof world.
- `IgulimYosher.agda`: Domain definition for Igulim and Yosher worlds.
- `Tzimtzum.agda`: Domain definition for the Tzimtzum world.

Usage:
```agda
import Hishtalshelut.Domain.Worlds.EinSof
```
