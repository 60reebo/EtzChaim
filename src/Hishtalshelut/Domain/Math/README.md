# Ordinals & Cardinals in EtzChaim

## Purpose
המערכת עושה שימוש בטיפוסים אורדינליים (Ordinal) וקרדינליים (Cardinal) כדי לייצג עומק, מבנה, עוצמה וקיבולת של אורות וכלים בשלבי ההשתלשלות. ייצוג זה מאפשר סימולציה פורמלית של תהליכים אינסופיים, טרנספיניטיים ודינמיקה של עולמות.

## Ordinal (סוד הספירה והעומק)
- **מהו Ordinal?**
  - מייצג "עומק" או "שלב" היררכי, בדומה למספר סודר (0, 1, 2, ..., ω, ω+1, ...).
  - תומך ב־succ (יורש), limit (גבול), limitTr (גבול טרנספיניטי), וחיבור/מקסימום.
  - דוגמאות: ω (ספירה אינסופית), ω² (שכבות אינסופיות), limitTr(ω, f) (גבול טרנספיניטי כללי).
- **שימושים במערכת:**
  - קביעת רמת עומק של אור/כלי, שלב בהיררכיה, או מיקום בעץ הספירות.
  - פונקציות לדוגמה: `iterateOrd`, `max`, `ordinalEq`, `showOrdinal`.

## Cardinal (סוד העוצמה והקיבול)
- **מהו Cardinal?**
  - מייצג "עוצמה" או "כמות" של אור/כלי, בדומה למספר עוצמה (0, 1, 2, ..., ℵ₀, ℵ₁, ...).
  - תומך ב־⊕ (חיבור), ⊗ (כפל), חזקה, aleph0, alephOmega, limitCard.
  - דוגמאות: ℵ₀ (עוצמת הטבעיים), ℵ_Ω (עוצמת כל האורדינלים הסופיים).
- **שימושים במערכת:**
  - חישוב עוצמת האור בכלי, קיבולת הכלי, חיבור/פיזור אורות.
  - פונקציות לדוגמה: `iterateCard`, `max`, `cardinalEq`, `showCardinal`.

## עקרונות שימוש
- כל אור/כלי נושא שדה Ordinal (עומק/שלב) ו-Cardinal (עוצמה/קיבול).
- כל חישוב דינמי (step) במערכת עושה שימוש באלגברה של Ordinal/Cardinal:
  - חיבור עוצמות: `a ⊕ b`
  - חיבור עומקים: `a + b` (Ordinal)
  - מקסימום: `max a b`
- המימוש מסתמך על פוסטולטים לא טריוויאליים (decOrdLE, וכו') עבור פעולות סדר והשוואה.
- המערכת תומכת גם באינסופיים (ω, ℵ₀) וגם בטרנספיניטיים (limit, limitTr, alephOmega).

## דוגמאות Agda
```agda
open import Hishtalshelut.Domain.Math.Ordinal
open import Hishtalshelut.Domain.Math.Cardinal

-- חיבור עומקים
let depth = succ (succ zero) + omega in ...

-- חיבור עוצמות
let power = aleph0 ⊕ 5 in ...

-- בדיקת סדר
if ord1 ≤? ord2 then ...
```

## גישות מתמטיות
- **פורמליזם טרנספיניטי:** מאפשר חישוב פורמלי של תהליכים אינסופיים (למשל, שבירת כלים או תיקון ברמות אינסופיות).
- **הפרדה בין עומק (Ordinal) לעוצמה (Cardinal):** כל שלב במערכת מחייב להבחין בין "כמה" (Cardinal) ל"איפה" (Ordinal).
- **הרחבה עתידית:** ניתן להוסיף גם אינפיניטסימלים, סדרות limit, ומודלים טופולוגיים.

## הערות
- יש להיזהר משימוש בפונקציות המסתמכות על פוסטולטים לא קונסטרוקטיביים.
- מומלץ להרחיב בדיקות יחידה לאורדינלים וקרדינלים טרנספיניטיים.
