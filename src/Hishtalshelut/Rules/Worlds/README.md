# Rules - Worlds

This directory contains rule implementations for each world.

Modules:
- `EinSofRules.agda`: Rules for EinSof world transformations.
- `IgulimYosherRules.agda`: Rules for Igulim and Yosher worlds.
- `TzimtzumRules.agda`: Rules for Tzimtzum world transformations.

Usage:
```agda
import Hishtalshelut.Rules.Worlds.TzimtzumRules
```
